# Черновики баннеров Speak-Y

Два набора заготовок для рекламного блока Speak-Y на сайте. Лежат в репозитории,
чтобы к ним можно было вернуться и заменить принятый вариант, не собирая всё заново.

| Файл | Что внутри |
|---|---|
| `banners-v1.html` | Серия 1, варианты 01–22: разные маркетинговые приёмы в палитре сайта |
| `banners-v2.html` | Серия 2, варианты 23–42: фирменные цвета Speak-Y, снятые со speak-y.com |

У каждой страницы вверху переключатели трёх тем сайта и двух ширин — главной
страницы и страницы исследования. Под каждым вариантом подписано, какой приём он
реализует и кому подходит.

**Сейчас на сайте стоит вариант 28 «outline»** — рамка фирменного синего, одна строка
«Voice input and meeting recording» и оранжевая кнопка «30 days free». Разметка живёт
в `index.html` (класс `.sy-banner`) и в `research/shell.css` (класс `.sy-strip`).

От черновика принятый вариант отличается двумя вещами: слева добавлена иконка приложения
(`images/icons/speak-y.webp`, 44 px на главной и 40 px в разделе), а имя «Speak-Y» поднято
над строкой оффера. Иконка стоит около 60 px ширины — в один ряд с именем строка оффера
после неё уже не помещалась, а в два уровня помещается с запасом. Побочная выгода: имя и
строка выровнены по левому краю, и разница базовых линий двух шрифтов больше не видна.
В черновиках этого варианта нет — там все 42 без иконки.

Фирменная палитра Speak-Y, снятая с сайта продукта:

| Токен | Значение |
|---|---|
| primary / accent | `#FF6700` |
| primary hover | `#E05A00` |
| primary light | `#FFF0E5` |
| text | `#004E98` |
| text secondary | `#3A6EA5` |
| background | `#F5F5F5` |
| border | `#DCDCDC` |

Страницы закрыты от индексации: `noindex` в разметке и `Disallow: /design/` в `robots.txt`.
